# Direction

Improve the language and shared culinary knowledge through representative recipes and human review. Keep the core useful without a particular website or host.

Future work includes locale-aware names, unit conversion and serving scaling that retain source precision; stronger evidence-backed ingredient/equipment/process relationships; and improved contributor workflows. Human browsing categories are distinct from semantic type_of relationships. A lightweight process browsing taxonomy is available for the first approved tranche. Broader process coverage and equipment categories remain future work; ingredient taxonomy needs research first.

The current package remains private and contains compiled code only. Distribution of knowledge data needs a separate decision. The locally extracted corpus and site currently use an explicit local source integration contract; publishing destinations and pinned release contracts can be decided later without changing core semantics.

Do not infer that a recipe or knowledge entry has been human-reviewed merely because it renders successfully or has passed structural tests.
